# Лабораторная работа по ТРПО
# ⚞ Сайт-визитка студента ⚟


Одностраничная визитка в терминальном стиле: тёмный фон, моноширинный шрифт и живой ASCII-фон. Без фреймворков и сборки, только HTML, CSS и JavaScript.

## Возможности

- **ASCII-фон.** Символы хаотично дрейфуют, отлетают от курсора, а по клику от точки нажатия расходится круговая волна. На телефонах работает касание.
- **Приветствие по времени.** «Доброе утро / Добрый день / Добрый вечер / Доброй ночи» в зависимости от часов на устройстве посетителя.
- **Scramble-эффект.** Текст «расшифровывается» из случайных символов при загрузке, смене языка и наведении на ссылки.
- **Два языка.** Переключатель RU | EN в углу, выбор запоминается.
- **Четыре цветовые схемы.** Зелёная, янтарная, фиолетовая, белая. Выбор запоминается, значок вкладки меняет цвет вместе со схемой.
- **Ссылки-команды.** `$ open github`, `$ open telegram`, `$ send email`
- **Строка статуса.** Локальное время и время, проведённое на странице.
- **Скрытый терминал.** Открывается по `~` 
- **Доступность.** При включённом «уменьшении движения» в системе фон статичный, а анимации отключены.
